连接 GitHub

管理页需要你的 GitHub 写入权限。令牌只保存在这台浏览器的 localStorage 里， 只会发给 api.github.com，不会出现在公开页面。

还没有令牌？去 GitHub 创建一个 Fine-grained token

怎么创建这个令牌？
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Resource owner 选 liuxiaoshigay；Repository access 选 Only select repositories → liuxiaoshigay.github.io。
  3. Permissions → Repository permissions → Contents 设为 Read and write；Issues 也设为 Read and write （用来读取和关闭投稿 Issue）。Metadata 会自动带上 Read。
  4. Generate token，复制 github_pat_...，粘到上面的输入框。

不要用 classic token；这个 fine-grained token 只对这个仓库有内容读写权限。 万一泄露，在同一页面 Revoke 即可。
