连接 Supabase

管理页用 Supabase 管理键登录。键只保存在这台浏览器的 localStorage 里， 只会发给你的 Supabase 项目；不需要 GitHub 令牌。

管理键忘了 / 还没设置？

管理键是在 Supabase SQL Editor 运行初始化 SQL 时最后一段设置的。忘了可以在 SQL Editor 重新运行：

update public.settings
set admin_key_hash = extensions.crypt('新的长随机串', extensions.gen_salt('bf'))
where id = 1;

然后把新串填到上面。
